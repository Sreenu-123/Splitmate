# 💸 SplitMate

### Split expenses. Stay balanced.

SplitMate is an expense-sharing application built with Flutter that makes managing shared expenses simple and convenient. It helps users organize groups, track expenses, calculate balances, and manage settlements in one place.

## ✨ Features

- **Group Management** – Create and manage expense-sharing groups.
- **Member Management** – Add members to existing groups.
- **Expense Tracking** – Record and organize shared expenses.
- **Expense Splitting** – Divide expenses among group members.
- **Balance Calculation** – Automatically calculate who owes whom.
- **Settlement Suggestions** – View suggested payments to settle outstanding balances.
- **Settlement Tracking** – Mark settlements as paid and track payment status.
- **Activity History** – View recorded expense and settlement activities.
- **Profile Management** – Manage profile information and preferences.
- **Currency Selection** – Choose from supported currencies.
- **Splash Screen** – Animated application launch screen.

## 🚀 Getting Started

Follow these steps to run SplitMate locally.

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Sreenu-123/SplitMate.git
```

**2. Navigate to the project directory**

```bash
cd SplitMate
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```
